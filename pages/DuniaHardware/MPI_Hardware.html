Materi Hardware

Hardware (Perangkat Keras) adalah semua komponen fisik pada komputer yang dapat dilihat dan disentuh.

Hardware dibagi menjadi 4 kelompok utama berdasarkan fungsinya:

  1. Input Device (Memasukkan data)
  2. Process Device (Memproses data)
  3. Output Device (Menampilkan hasil)
  4. Storage Device (Menyimpan data)

Klik tab di atas untuk mempelajari masing-masing kelompok!

Perangkat Masukan (Input Device)

Berfungsi untuk memasukkan data atau perintah ke dalam komputer.

Mouse

Menggerakkan kursor dan klik

Keyboard

Mengetik teks dan angka

Microphone

Memasukkan suara

Scanner

Memindai dokumen fisik ke digital

Perangkat Pemroses (Process Device)

Berfungsi sebagai "otak" komputer untuk memproses instruksi dan data.

CPU / Prosesor

Otak utama yang memproses data

RAM

Penyimpanan sementara saat komputer menyala

Motherboard

Papan induk penghubung semua komponen

VGA Card

Memproses grafis / visual

Perangkat Keluaran (Output Device)

Berfungsi menampilkan atau menghasilkan informasi yang telah diproses.

Monitor

Menampilkan visual/gambar dari komputer

Printer

Mencetak dokumen digital ke kertas

Speaker

Menghasilkan suara/audio

Proyektor

Menampilkan layar ke dinding/layar besar

Perangkat Penyimpanan (Storage Device)

Berfungsi menyimpan data dan sistem operasi secara permanen.

Hardisk (HDD)

Penyimpanan kapasitas besar menggunakan piringan magnetik

SSD

Penyimpanan cepat tanpa komponen bergerak

Flashdisk

Penyimpanan portabel kecil melalui port USB

CD/DVD

Penyimpanan berbentuk kepingan optik
