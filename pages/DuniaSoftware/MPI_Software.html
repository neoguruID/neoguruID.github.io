Materi Software

Software (Perangkat Lunak) adalah kumpulan data elektronik atau instruksi yang disimpan dan diatur oleh komputer.

Berbeda dengan hardware, software tidak memiliki wujud fisik yang bisa disentuh, namun ia yang mengendalikan hardware agar bisa bekerja!

Software secara umum dibagi menjadi 4 kategori:

  1. Sistem Operasi (OS) - Pengelola utama sistem.
  2. Software Aplikasi - Untuk tugas sehari-hari.
  3. Software Utilitas - Memelihara komputer.
  4. Bahasa Pemrograman - Untuk membuat software baru.

Klik tab di atas untuk mempelajari tiap kategori!

Sistem Operasi (Operating System)

Software paling dasar yang menjembatani hardware dan pengguna. Tanpa OS, komputer atau HP tidak bisa menyala dan digunakan.

Windows

OS buatan Microsoft paling populer untuk PC.

macOS / iOS

OS khusus buatan Apple (Macbook / iPhone).

Android

OS paling populer untuk Smartphone (HP).

Linux

OS open-source yang kebal virus & sering untuk server.

Software Aplikasi

Software yang dibuat untuk membantu manusia mengerjakan tugas-tugas spesifik sehari-hari.

Pengolah Kata

Contoh: Microsoft Word, Google Docs.

Web Browser

Untuk berselancar di internet (Chrome, Firefox).

Desain Grafis

Mengedit foto/desain (Photoshop, Canva).

Game/Hiburan

Aplikasi permainan (Roblox, Minecraft, Spotify).

Program Utilitas (Utility)

Software yang bertugas memelihara, melindungi, atau menganalisis kinerja komputer.

Antivirus

Mencegah & menghapus virus (Smadav, Windows Defender).

Kompresi File

Mengecilkan ukuran file (WinRAR, WinZip).

Disk Cleaner

Membersihkan file sampah / cache.

Defragmenter

Merapikan data di Hardisk agar komputer cepat.

Bahasa Pemrograman

Software yang digunakan oleh Programmer (pembuat aplikasi) untuk menulis kode instruksi komputer.

Python

Bahasa populer untuk AI dan pemula.

Java

Banyak digunakan untuk aplikasi Android dan Game (Minecraft).

HTML & CSS

Dasar pembuatan desain dan struktur website.

C++

Bahasa tingkat tinggi untuk membuat OS atau mesin Game berat.
